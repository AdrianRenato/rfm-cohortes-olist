# 🛒 Análisis RFM y Cohortes - E-commerce Olist (Brasil)

Segmentación de clientes y análisis de retención utilizando **Python** 
y **pandas**, aplicando el modelo RFM (Recencia, Frecuencia, Monetario) 
y análisis de cohortes sobre datos reales de un marketplace 
latinoamericano.

## 📊 Sobre el dataset

Los datos provienen del dataset público **"Brazilian E-Commerce Public 
Dataset by Olist"** disponible en [Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce), 
con información de más de 99,000 pedidos entre 2016 y 2018.

## 🎯 Preguntas que respondí

1. ¿Quiénes son los clientes más valiosos de Olist?
2. ¿Qué porcentaje de clientes vuelve a comprar?
3. ¿Cómo se retienen los clientes mes a mes desde su primera compra?

## 🔍 Hallazgos principales

- El **97%** de los clientes de Olist compró una sola vez
- Solo el **0.2%** de los clientes son verdaderamente recurrentes/leales
- **15,275 clientes "Nuevos de alto valor"** representan la mayor 
  oportunidad de fidelización

## 🛠️ Herramientas

Python, Pandas, Google Colab
